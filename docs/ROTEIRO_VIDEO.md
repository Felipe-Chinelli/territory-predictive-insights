# Roteiro do vídeo (máx. 3 minutos)

Grave a tela do emulador/celular com narração (ou legenda). Antes de gravar: dados limpos (Ajustes → Apagar meus dados), idioma e tema claro, internet ligada.

| Tempo | Tela | O que mostrar e falar |
|---|---|---|
| 0:00–0:15 | Consentimento | "Territory Predictive Insights antecipa a demanda por serviços públicos em Aurora do Vale." Marcar o aceite e entrar. Destacar que não coletamos dados pessoais. |
| 0:15–0:40 | Visão geral | KPIs, aviso de decisão humana, **benefício social** (prazo, equidade, população com alerta revisado). Mencionar a origem dos dados (clima real + demanda sintética). |
| 0:40–1:10 | Painéis | Percorrer os **3 painéis**: Demanda (previsão tracejada), Territórios (filtrar uma região) e Clima × demanda (chuva prevista). |
| 1:10–2:00 | Alertas | Abrir **um alerta**: evidências, **confiança** (e como é calculada), **limitações e vieses**, sugestão. Mostrar o aviso "decisão final é humana" e **aceitar o alerta** com justificativa. Voltar e mostrar o badge/estado "decidido". |
| 2:00–2:15 | Indicador | Abrir o detalhe de um indicador (fluxo visão geral → indicador → alerta). |
| 2:15–2:35 | Ocorrências | Lista vazia → formulário: enviar vazio (erros), preencher com telefone/e-mail no texto e registrar. Mostrar que o dado pessoal foi removido. |
| 2:35–2:50 | Ajustes | Alterar limiar (alertas recalculam), alto contraste/fonte maior e tema escuro. Ligar "Simular falha de rede" para mostrar o estado de erro e voltar. |
| 2:50–3:00 | Fechamento | "Funciona offline com dados em cache, e os alertas apoiam, mas não substituem, a decisão humana." |

Checklist: ≤ 3 min · mostra um alerta sendo gerado e sua justificativa · todas as telas principais · voz ou legenda · imagem e áudio nítidos · link público (YouTube não listado ou Drive com acesso a qualquer pessoa).
